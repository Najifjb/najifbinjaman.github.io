ধাপ ১: নতুন কোডটি `index.html`-এ বসান গিটহাবে আপনার index.html ফাইলে গিয়ে পেন্সিল আইকনে (✏️ Edit) ক্লিক করুন। আগের সব কোড মুছে এই নতুন কোডটি Paste করে Commit changes করুন।
ধাপ ২: আপনার নিজের ছবি (`profile.jpg`) যেভাবে বসাবেন আপনার নিজের যে ছবিটি ওয়েবসাইটে দেখাতে চান, সেটির নাম বদলে (Rename করে) profile.jpg রাখুন। এরপর গিটহাবে Add file ➔ Upload files-এ গিয়ে ওই profile.jpg ছবিটি আপলোড করে Commit changes দিন—কোডে আর হাত দিতে হবে না, অটোমেটিক আপনার ছবি চলে আসবে!
ধাপ ৩: ব্রাউজারে Hard Refresh দিন ১ মিনিট অপেক্ষা করে আপনার ওয়েবসাইটে গিয়ে Ctrl + Shift + R চাপুন (মোবাইলে পেজ রিলোড দিন)।
